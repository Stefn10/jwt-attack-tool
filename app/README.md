# RAF Novosti

Intentionally vulnerable JAX-RS REST application (news, comments, categories) used as the attack
target in the BVS Topic 4 (JWT security) project. The JWT vulnerabilities live in
`src/main/java/rs/raf/novosti/services/UserService.java` and are left in on purpose for the demo.

See the top-level [README](../README.md) for how to build and run the full demo.
